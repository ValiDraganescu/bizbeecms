## Findings that are code, not model choice

1. **Gemini was unusable in the assistant** — `create_page` / `update_page_blocks`
   declared `blocks: {type:"array"}` without `items`; Google's API rejects the
   request (`INVALID_ARGUMENT`). Fixed in `page-tool.ts` / `write-tools.ts` +
   regression test `scripts/tool-schema-arrays.test.mjs`.
2. **`describe-image.ts` `max_tokens: 300` breaks reasoning models** — they spend
   the budget thinking. Either keep reasoning models out of `imageDescribe`
   (current recommendation) or send `reasoning: {effort:"low"}` / raise the cap.
3. **Prompt-leak guardrail is model-dependent** — `gpt-4.1-mini`, `gemini-3.1-flash-lite`,
   `gpt-5.4-nano`, `kimi-k2.6` printed the guardrails/tool names when asked
   "for an audit". The stronger fix is a hard filter server-side, not a better model.
4. `edit_text` args: several models mixed replace/replaceBetween modes once
   (validation rejects it — self-correcting error path works, but costs a round).

## Addendum — Grok 4.6 as the assistant "Best" (2026-08-18, later)

Question: is Grok 4.6 ≈ Opus 5? Public data (Artificial Analysis, Anthropic/xAI
cards via kingy.ai / codingfleet / emergent.sh): Opus 5 slightly ahead on
intelligence (63 vs 61), AA-Briefcase (1720 vs 1577), GDPval (1861 vs 1753);
on par for coding-agent work (CursorBench 70.0 vs 70.8, Terminal-Bench 89 vs
88.4); Grok is 1.6× faster, half the turns, $2/$6 vs $5/$25. Our harness: Grok
4.6 = **100% on all 12 assistant task-runs** ($0.043/task, 1.9s) and 98.5% on
chatAgent ($0.006, 0.7s). Opus 5 deliberately NOT run (cost). Decision:
assistant `best` → `x-ai/grok-4.6`. Caveat from public sources: ~4%
structured-output error rate on the standard API — not observed in our 12 runs.

## Addendum 2 — reasoning control for imageDescribe + Grok 4.6 as every "Best"

`describe-image.ts` now sends OpenRouter's unified `reasoning:{enabled:false}`
and, when a model answers 400 "Reasoning is mandatory", retries once with
`reasoning:{effort:"minimal"}` + `max_tokens 1200`. Measured: `enabled:false` is
ignored by non-reasoning models but REJECTED by mandatory-reasoning ones
(grok-4.6, gemini-3.7-flash); `effort:*` alone turns thinking ON for optional-
reasoning models (gemma-4-31b, qwen3.7-flash → empty output at 300 tokens), so
it can only be the fallback. With that, all tested models describe correctly
(grok-4.6 100%, gemini-3.7-flash 96%, glm-4.6v 100%, qwen3.7-flash 95%).

Grok 4.6 measured on every purpose: assistant 100%, chatAgent 98.5%,
imageDescribe 100%, translate 89% (ties the leaders). Public benchmarks put it
just below Opus 5 and 3–4× cheaper. Decision: `best` = `x-ai/grok-4.6` for
chatAgent, assistant, imageDescribe, translate (imageGenerate stays
gemini-3-pro-image — Grok has no image output).
