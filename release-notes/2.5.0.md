# CMS v2.5.0

_2026-07-24 · changes since r-2.4.0_

## Features
- **Per-component "Translate missing" button.** The block inspector now has a one-click button next to the component name that fills every missing translation across all of that block's text props at once — it only appears when something is missing and disappears when done.
- **Lists: translate the item component's fixed texts.** A List's item-component text props that aren't mapped to a data field (e.g. a "New!" badge or "Book a table" button label) are now editable per language in a new "Item text" section of the List settings — with the same language tabs and AI translate as everywhere else. Every row renders them in the visitor's language.

## Fixes
- Two translations running at the same time on one block (e.g. title and subtitle) no longer overwrite each other — whichever finishes last used to reset the other's result, and could also wipe text typed while a translation ran.
- The page-level "Translate missing" now also covers text props that were never edited and still show their component default — previously those were silently skipped until touched once. All three translate buttons (per field, per block, per page) now use the same rule.
- The AI-assistant chat bubble no longer covers the last controls of the settings panel — they now scroll clear of it.

## Other
- The block-binding settings screen was split from one 1600-line file into focused per-panel files (List, Form, binding controls) for maintainability.
