# CMS v2.9.0

_2026-08-18 · changes since r-2.8.0_

## Features
- Project Manager exposes an MCP endpoint (`/mcp`) protected by a built-in OAuth 2.1 authorization server, so MCP clients (Claude Code, etc.) can connect to your PM account; a new **Settings → Connections** page lists and revokes authorized clients.
- New Site form auto-generates the slug from the name as you type and checks live that it's not already taken.

## Other
- Custom domain panel: removed the generic "Setting up a custom domain" guide — the panel now shows only the exact DNS records for the domains you entered.
