# CMS v3.1.0

_2026-08-18 · changes since r-3.0.0_

## Features
- AI models settings: every purpose now ships three curated tiers — **Fast** (default), **Cheap** and **Best** — picked from a real benchmark of OpenRouter models against the CMS's own prompts and tools; the assistant's Best tier is now Grok 4.6 (top score, ~4× cheaper than Opus 5).
- Each alias shows OpenRouter prices per 1M tokens (input, cached input, output, cache write) so cost trade-offs are visible when choosing a model.
- Assistant purpose only offers vision-capable models (image input is required for page/design work); the picker and MCP filters enforce this.
- PM MCP tools for Settings → AI models: browse the OpenRouter catalog with per-purpose capability filters, and add/update/remove curated aliases (Admin+).

## Fixes
- Gemini models failed on any AI chat that included the page tools: `create_page` / `update_page_blocks` declared `blocks` without an item schema, which Gemini rejects. Fixed with a regression test.
- OpenRouter's "-1" (dynamic-router) prices are treated as unknown instead of cheapest.

## Other
- `CMS/scripts/ai-bench`: reproducible benchmark harness scoring models on the 5 AI purposes with results + recommendations (2026-08-18).
