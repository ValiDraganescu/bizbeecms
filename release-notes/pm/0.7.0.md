# ProjectManager v0.7.0

_2026-08-19 · changes since r-3.1.1 (first tagged PM release)_

## Features
- Navigation reorganised into sidebar sections with a site switcher, so jumping between Sites and settings is one click.
- Site page: assignment and tags are edited in place on the Site's edit cards (the separate assign/tags forms are gone).
- User invites live under Users (pending invites + invite form in one place).
- MCP tools `sites_list`, `sites_create` and `tags_list` — `sites_create` runs the exact same authorization / country-scope / slug-uniqueness / tag flow as the browser form, so an assistant can never create a Site the user couldn't.

## Other
- Dropped the unused `next lint` scripts.
