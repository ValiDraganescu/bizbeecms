# CMS v3.1.1

_2026-08-18 · changes since r-3.1.0_

## Fixes
- Image descriptions (alt text / media search) no longer come back empty on "thinking" models. The describe call now switches reasoning off; models that cannot turn it off (e.g. Grok 4.6, Gemini 3.7 Flash) get one automatic retry with minimal thinking and a larger output budget, so every curated model produces a real description.

## Other
- AI model benchmark (`scripts/ai-bench`) now exercises the real `describeImage()` path; results informed the new Best/Fast/Cheap catalog in the ProjectManager (Best = Grok 4.6 for chat, assistant, image description and translation).
