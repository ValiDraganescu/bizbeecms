# CMS v2.6.0

_2026-07-25 · changes since r-2.5.0_

## Features
- **AI credits & usage page.** Settings → AI → Credits & usage shows your allocated monthly AI credits, what's been used and what remains — the same numbers the quota enforces on — plus all-time spend, a last-30-days daily chart, and a per-feature breakdown (chat agents, admin assistant, image tools, translation). Daily and per-feature history starts accruing from this release; earlier spend is included in the monthly and all-time totals.
- **Export & import chat agents.** The Chat agents screen can now export selected agents to a single file (configuration only — no conversations or usage data) and import them on any site. Imported agents are always created as new — a name clash becomes a "name-2" copy, never an overwrite — and references to collections or data sources the site doesn't have are dropped with a warning naming exactly what to reconnect.
