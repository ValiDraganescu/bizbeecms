# CMS v3.3.0

_2026-08-21 · changes since r-3.2.1_

## Features
- Form blocks now ship with invisible ALTCHA proof-of-work bot protection: visitors solve nothing visible, bots pay a compute cost, and each challenge is single-use so submissions can't be replayed.
- Site logo setting on the theme page: pick or upload your brand mark from the media library, and the AI sees it through `get_theme`/`update_theme` so authored headers and footers use the real logo instead of a placeholder.
- New `upload_asset` AI tool: MCP clients (e.g. a local Claude Code) can upload files straight into the Site's media library and get back the public URL.
- "Translate missing" in the page builder now opens a preview dialog first, listing every item that lacks translations and exactly which languages are missing, so you confirm before any translation is produced.
- Rows support a "stretch" vertical alignment: repeated cards in a row grow to equal height.

## Fixes
- "Translate missing" no longer reports (or re-translates) text a component already provides in every language through its per-language authored defaults.
- Component props/attributes with short names (`src`, `alt`, `id`, `rel`…) are no longer misread as language maps, which could collapse a whole prop bag into a single value.
- Images with an aspect-ratio utility class keep it: the automatic inline aspect-ratio fill now steps aside instead of fighting the class.

## Other
- New authoring lint scripts for site quality sweeps: external-link hygiene, repeated-item consistency, and section padding.
