# CMS v2.7.0

_2026-08-18 · changes since r-2.6.1_

## Features
- **Full CRUD over MCP / AI chat**: data sources, saved requests, collections, collection fields, collection items and chat agents can now be *updated* and *deleted* by the AI assistant and MCP clients — not just created. All updates follow one patch contract: omitted = keep, `null` = reset/clear.
  - `update_data_source` (partial patch, write-only secret rotation, auth transitions), `set_data_source_request` (upsert with per-key query merge, stable ids), `delete_data_source` / `delete_data_source_request`.
  - `update_chat_agent` no longer resets model/limits when you only change the system prompt; `set_chat_agent_data_source` / `_collection` are merge patches; per-locale welcome messages merge.
  - `update_collection` (label, description, public submissions), `update_collection_field` (description/required/default/type — type changes ride the schema rebuild and report the exact coercion applied), `delete_collection`, `restore_collection_item`, and permanent `delete_collection_item` (distinct from archive).
- **Guarded deletes**: deleting a data source, request or collection is refused while pages, components or chat agents still reference it — the error names every referencing entity and the tool that removes the reference. Guards fail closed on unreadable page data.
- **`edit_text` gets a `replaceBetween` mode** (exact start/end markers, occurrence, near-miss hints) and new targets: chat-agent system prompt / welcome message, data-request body template, and text/richtext collection item fields.
- **Authoring guides updated** (data sources, chat agents, tool scopes) to describe the patch surface, guarded deletes and the new edit_text targets.

## Fixes
- `bodyTemplate` on data-source requests is now validated to be valid JSON *after* placeholder substitution, across create/update/edit_text and the Admin REST routes.
- `update_chat_agent` rejects unknown `limits` keys by name instead of silently resetting every limit.
- `update_collection_field required:true` over rows with NULLs is pre-checked and back-filled from the supplied default in the same call.

## Other
- Custom-domain certificates: after each Site deploy, active custom hostnames still on TXT validation are switched to HTTP validation so cert renewals complete without the customer re-adding `_acme-challenge` TXT records (fixes the "validate your domain to renew" emails).
- Operator tooling: `scripts/prod-connect.mjs` / `/prod-connect` skill to run a local CMS/PM against a Site's production D1/R2 for debugging, and restore local.
- Internal: tool-dispatch split into per-domain handler modules; chat-agent tool schemas separated; shared arg validators.
