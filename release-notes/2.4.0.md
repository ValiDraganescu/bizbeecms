# CMS v2.4.0

_2026-07-24 · changes since r-2.3.1_

## Features
- **Translate everything missing in one click.** Three new actions fill every absent translation at once — existing translations are never touched, only gaps are filled:
  - **Item editor**: "Translate missing" fills all empty languages across every translatable field of the open item into your draft (you still press Save).
  - **Collection toolbar**: "Translate all missing" sweeps the whole collection — skips already-complete items without spending AI budget, shows "Item 3/6" progress, saves each item as it finishes, and ends with a summary (updated / added / skipped / failed). One item failing doesn't stop the rest; running out of AI quota stops the sweep cleanly.
  - **Page builder**: "Translate missing" covers the page's SEO title/description and every translatable component text on the page.
- Adding a new language to your site is now a one-click backfill per collection or page instead of one translate per field.

## Fixes
- Bulk and per-field translations can no longer overwrite content edited while a translation is running — the latest saved text always wins, and saves re-read the current item first.

## Other
- Large admin screens decomposed for maintainability (collection content screen, page-builder shell); shared translate networking unified into one client with a single timeout/error path.
